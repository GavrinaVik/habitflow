# Видео-обзор HabitFlow (15 мин) — сценарий

> Снять можно в OBS Studio / Loom / Camtasia. Формат: 1080p, 16:9, 60 fps.
> Внизу — таймкоды и «экраны». Перед записью: `npm run dev`, открыть `http://localhost:5173`.

## 0:00 — Интро (0:30)
- Что такое HabitFlow: SaaS трекинга привычек с геймификацией.
- Структура ролика: экраны → ключевые функции → админка → архитектура.

## 0:30 — Лендинг и тарифы (1:30)
- Hero с интерактивным демо, «Как это работает», возможности, отзывы, FAQ.
- `/pricing`: переключатель месяц/год, карточки Free/Pro/Premium, таблица сравнения.

## 2:00 — Регистрация и вход (2:00)
- Регистрация по email (валидация, индикатор сложности пароля).
- Показ письма подтверждения/onboarding в логе (админка → или `/api/email/log`).
- Вход через соцсети: VK, Google, Telegram (список соцвходов на `/login`).

## 4:00 — Личный кабинет (3:30)
- Создание привычки: цель, единицы, частота, напоминание.
- Чек-ин «Сделал / Не сделал», прогресс-бар, серия, конфетти на 100%.
- Детальная страница: график (неделя/месяц/всё время), статистика, история, экспорт CSV.

## 7:30 — Оплата ЮKassa (2:00)
- Кнопка «Оплатить» → создание платежа → демо-страница `/pay/:id`.
- «Оплатить» → webhook `payment.succeeded` → тариф Pro активирован, `planExpiresAt` в настройках.
- Чек в логе писем; платёж в админке.

## 9:30 — Интеграции (2:30)
- Google Calendar (Premium): подключение → mock-consent → синк событий.
- Настройки: подписка, рассылка (вкл/выкл).
- «Поделиться»: генерация Stories 1080×1920, публикация в Instagram/VK.
- Метрика: цели в консоли (`__METRIKA_HITS__`) — регистрация, оплата, чек-ин.

## 12:00 — Админка (2:00)
- Вход `admin@habitflow.app`/`admin123` → `/admin`.
- Дашборд (users, MRR, конверсия), пользователи (смена тарифа/блок), платежи (CSV), контент (мотивации, FAQ, бонусы), настройки (цены, шаблоны писем), аудит.

## 14:00 — Архитектура и деплой (1:00)
- Monorepo (npm workspaces): `client/` (React+Vite) и `server/` (Express, in-memory).
- Мок-интеграции легко заменяются на реальные через env: ЮKassa/Unisender/Google/Metrika.
- Безопасность: bcrypt, JWT httpOnly SameSite cookie, CORS-whitelist, rate limiting.
- Деплой: Vercel (frontend) + Railway (backend) + Supabase. Ссылка на README.

## 15:00 — Аутро (0:10)
- Приглашение попробовать; комментарии/вопросы.
